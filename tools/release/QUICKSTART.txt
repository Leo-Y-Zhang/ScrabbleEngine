Tilefish - a crossword game engine
==================================

To play without installing anything, open
     https://leo-y-zhang.github.io/ScrabbleEngine/
in any browser. This download is the full engine: every core, game review, analysis.

1. Start Tilefish:
     Windows:        double-click tilefish.exe
     macOS / Linux:  ./tilefish   (or double-click it)
   It plays ENABLE, a free word list that comes with it. Two more free lists come
   with it too: type   lexicon CEL.txt   for everyday words only (the Common English
   Lexicon), or   lexicon OXENDICT.txt   for British English in Oxford spelling.

2. Tournament lists. Collins Scrabble Words 2024 (CSW24) and the NASPA Word List 2023
   (NWL2023) belong to HarperCollins and NASPA, so they are not included and Tilefish
   does not download them. If you have a copy you are entitled to use (a text file,
   one word per line, or a .kwg file), save it in this folder as CSW24.txt or
   NWL2023.txt (or .kwg) and Tilefish uses it when it starts; or start
   tilefish --lexicon /path/to/your/list. Tilefish's own leave values and win models
   for both lists (CSW24.klv2, NWL23.klv2, CSW24.win, NWL23.win) come with it.

3. Type one of these at the  tilefish>  prompt:
     play                 play a game against it at full strength (about 12 s a move)
     play sim             a quicker game (up to 2 s a move)
     review mygame.gcg    go through a game move by move: what you lost where
     help                 everything else (positions, endgames, analysis, matches)

If macOS says the program cannot be opened, type   xattr -d com.apple.quarantine tilefish
If Windows SmartScreen warns, choose "More info" and then "Run anyway".
